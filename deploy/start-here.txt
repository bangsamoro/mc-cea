===========================================================
 MC-CEA  -  publish to B   (quick start, read this on C)
===========================================================

You are on the C box. Everything you need is in this folder.

The portal replaces B's home page, so it lands in the docroot
and goes live at   http://B-HOST/   (inside KSU only).

--- one time only -----------------------------------------

1. WinSCP must be installed (C:\Program Files (x86)\WinSCP\).

2. Tell the kit how to reach B. Pick ONE:

   A) a local connection file - no GUI needed. Run:

        echo sftp://root@B-HOST/> "C:\Users\DELL\MCCEA\deploy\connection.local.txt"

      (change "root" if your SSH user differs; the file is
       git-ignored, so the address stays off GitHub)

   B) a saved WinSCP session - open WinSCP, New Session:
        protocol SFTP, host B-HOST, port 22, your user
        -> Save -> name it exactly:  B
        -> log in once, ticking "Save password"

   See what sessions you already have:

        reg query "HKCU\Software\Martin Prikryl\WinSCP 2\Sessions"

3. If WinSCP has never connected to B from this machine,
   connect once in the GUI and accept the host key.

--- every deploy -------------------------------------------

   git pull
   deploy\deploy-mc-cea.bat

   It prints "Connecting :" first, so you can see which
   connection it picked, then uploads this folder into B's
   docroot /var/www/html. Nothing else there is deleted -
   ifr\, tag\ and phpmyadmin\ stay exactly as they are.

--- if something goes wrong ---------------------------------

   Log:  %TEMP%\mc-cea-deploy.log

   "Looking up host" / "Host does not exist"
        -> no connection file and no saved session B. Do step 2.
   "Authentication failed" / password prompt
        -> save the password in the WinSCP session.
   "No index.html found"
        -> wrong folder. Run: deploy-mc-cea.bat D:\your\folder

--- what does NOT get uploaded ------------------------------

   deploy\   preview\   assets\   *.md   .git*   *.log
   .htaccess  (B may already have one at the docroot; ours
               would affect ifr\ and tag\, so it is skipped)

Full details: deploy\readme.md
